# Editor local

En Windows, abre la carpeta del repositorio y haz doble clic en `editor/iniciar_editor.bat`. Requiere Python 3. El navegador se abre en http://127.0.0.1:8765/. Mantén la ventana del servidor abierta mientras editas.

Guardar añade un establecimiento a `data/establecimientos.geojson.json`, con copia previa en `backups/`. Los cambios no se publican automáticamente. El servidor escucha solo en 127.0.0.1. No expongas este puerto a Internet ni introduzcas tokens en el frontend público.
